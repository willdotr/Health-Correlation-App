# Health Correlation App

**By:** Willie Robinson

Features
- **Data preview:** a description of the dataset and a table of the filtered rows.
- **Pairwise view:** pick any two variables to see a scatter plot with a linear trend line, the correlation r and the number of participants n. Points can be colored by a health threshold (for example SBP ≥ 130 or BMI ≥ 30).
- **Correlation heatmap:** choose which variables to include. Every square shows its coefficient and n, and the color scale is fixed from −1 to 1 so colors are comparable across filters.
- **Filters:** sidebar controls for sex and age range update every view: the table, scatter plot, r, n and heatmap.
